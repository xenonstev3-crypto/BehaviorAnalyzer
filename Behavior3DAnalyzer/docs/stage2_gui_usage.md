# 阶段 2 GUI 使用说明

## 当前范围

本界面只完成两个页面：`导入数据` 和 `重建坐标系`。没有任何 cylinder 触壁判断、左右使用比例或论文报告功能；这些必须在真实坐标重建经实验人员确认后才会实现。

## 用模拟数据验证

1. 在项目根目录运行 `python run_gui.py`。
2. 在“导入数据”选择 `sample_data/simulated_cylinder_trial.csv`。状态应显示导入成功、5 帧、单位 `mm`、fps `30`，并列出身体点和环境点。
3. 选择 `sample_data/simulated_trial_metadata.json`。
4. 到“重建坐标系”，选择 `A. metadata 直接参考`，选择一个空的独立结果目录，点击“验证参考并生成重建结果”。
5. 成功后会生成 `reconstructed_simulated_cylinder_trial.csv` 与同名的 `*_transform_record.json`。新 CSV 的 `cylinder_bottom_center_reconstructed_x/y/z` 首帧均应为 0；桶顶的重建 Z 应为 300。

不要把输出目录设为原始 CSV 所在文件本身；程序会拒绝相同输入/输出文件路径，也会拒绝覆盖已经存在的输出文件。

## 三种参考来源

- **A. metadata 直接参考**：最推荐。metadata 的 `coordinate_reference` 应含底面圆心、顶部中心/竖直向量和 X 参考。
- **B. CSV 固定环境标记**：使用三个每帧重复的固定点。最大漂移门槛必须与坐标单位一致；超出门槛时不生成结果。
- **C. 底面圆周点拟合**：填写至少三个不共线圆周点、明确的 +Z 向量、X 标记、半径及拟合残差门槛。

顶视/侧视图只用于快速核对坐标范围和轴向；它不是标定正确性的证明。请结合实验装置定义确认：底面圆心、桶顶、+X 和单位是否真实无误。

## 真实数据前的确认清单

请先准备一个脱敏的小型真实 CSV 与 metadata，确认：

- 每个固定点不是动物点，且其命名与 CSV 真实列完全一致；
- `coordinate_unit`、圆桶半径和高度的单位一致；
- 底面圆心到桶顶的向量确实是实验室定义的向上；
- 哪个点代表左/右前爪指尖或腕部；
- 固定标记允许的最大漂移和圆/平面残差由实验学判断确定。
