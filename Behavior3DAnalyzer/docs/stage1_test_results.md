# 阶段 1 测试说明

测试命令：`python -m unittest discover -s tests -v`。

2026-09-10 在当前 Windows Python 环境实际运行结果：**10/10 通过**。

测试使用内存中的合成 trial：先在已知圆桶坐标系中放置圆心、桶顶、圆周点和爪点，再施加已知旋转和平移生成原始坐标。测试覆盖：

1. 已知平移/旋转后恢复预期圆桶坐标；
2. 底面圆心回到 `(0,0,0)`，桶顶沿正 Z，圆周点半径正确；
3. X 参考和 Z 参考近平行时拒绝重建；
4. 环境标记缺列或漂移过大时拒绝重建；
5. 多点圆周标记共线时拒绝拟合；
6. 一个 trial 内单位不一致时拒绝输入；
7. 输出路径等于原始 CSV 时拒绝写入，且源文件 SHA-256 在测试前后相同。

测试不分析真实动物数据，不覆盖项目外的源 CSV。每次正常输出还会生成 `*_transform_record.json`，其中记录输入文件 SHA-256。
